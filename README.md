# aportAR: Plataforma solidaria de intercambio local

## Descripción del proyecto

**aportAR** es una plataforma web diseñada para facilitar la solidaridad vecinal, permitiendo a los usuarios ofrecer y solicitar servicios o donaciones de manera flexible y local.  
En un contexto de necesidades crecientes, esta herramienta conecta a vecinos de un mismo barrio o distrito para fomentar la colaboración directa, rápida y segura sin depender exclusivamente de organizaciones formales.

---

## Planteamiento del problema

Ante la compleja situación económico-social actual, muchas personas desconocen cómo o a quién recurrir para solicitar ayuda.  
La tecnología puede ser un aliado fundamental para conectar a quienes necesitan apoyo con quienes pueden brindarlo, fortaleciendo el sentido de comunidad y facilitando la coordinación de colaboraciones locales.

---

## Objetivos

### Objetivo general

Desarrollar una plataforma web local que conecte a vecinos para ofrecer y solicitar ayuda solidaria en forma de servicios o donaciones, promoviendo la colaboración comunitaria y el apoyo mutuo.

### Objetivos específicos

- Implementar un sistema de registro y gestión de usuarios según su rol (donante, oferente, solicitante).  
- Crear funcionalidades para publicar, buscar y gestionar ofertas y solicitudes dentro de una comunidad geográfica.  
- Incorporar un canal privado para que los usuarios coordinen detalles de donaciones o servicios.  
- Establecer un módulo administrativo para gestionar usuarios.  
- Garantizar seguridad y privacidad en los datos y comunicaciones.  
- Facilitar una interfaz intuitiva para usuarios con distintos niveles tecnológicos.  
- Promover la autogestión y responsabilidad vecinal en la coordinación de ayudas.

---

## Destinatarios

Personas en situación de vulnerabilidad por razones económicas, de salud, edad u otras circunstancias, así como quienes desean colaborar activamente con su comunidad.

---

## Tecnologías utilizadas

- Python 3.x  
- Flask (framework web)  
- MySQL (base de datos)
